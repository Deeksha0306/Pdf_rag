How it works: Text is extracted with pypdf, split into ~400-word chunks with 60-word overlaps, embedded using Google's text-embedding-004 model, then retrieved by cosine similarity. Top chunks are sent to gemini-2.5-flash as context.

API key is read from GEMINI_API_KEY in your .env file — never in source code.
